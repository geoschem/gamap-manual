# Support Guidelines

These pages are maintained by the **GEOS-Chem Support Team (GCST)**, which is based jointly at Harvard University and Washington University in St. Louis.

## GAMAP is no longer supported

GAMAP is no longer actively maintained, and the GCST does not provide support for installing, running, or debugging GAMAP or IDL. This repository only preserves the [GAMAP manual pages](https://geoschem.github.io/gamap-manual) for reference. We recommend that GAMAP users migrate to **[GCPy, our GEOS-Chem Python Toolkit](https://gcpy.readthedocs.io)**.

## How to report a problem with these pages

If you find a problem with the manual pages themselves, such as a broken link, a missing image, or a page that does not display, please **[open a new issue](https://github.com/geoschem/gamap-manual/issues/new)**. Please include your name, institution, and the URL of the page.

## Where can I ask for help with GCPy or GEOS-Chem?

- For GCPy questions, **[open a new issue in the GCPy repository](https://github.com/geoschem/gcpy/issues/new/choose)**.
- For GEOS-Chem questions, **[open a new issue in the GEOS-Chem repository](https://github.com/geoschem/geos-chem/issues/new/choose)**.

## How to report a security vulnerability

Please see [SECURITY.md](SECURITY.md). Do not report security vulnerabilities in public issues.
