# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repository is

This repository preserves the manual pages for GAMAP (Global Atmospheric Model Analysis Package), an IDL toolkit for GEOS-Chem output. GAMAP is no longer actively maintained, and users are pointed to GCPy (https://gcpy.readthedocs.io). The repository holds only static HTML/CSS/images. It has no GAMAP source code and no build, lint, or test tooling. GitHub Pages serves `main` directly at https://geoschem.github.io/gamap-manual, so whatever is committed to `main` is what gets published.

To preview locally, run `python3 -m http.server` from the repo root and open http://localhost:8000/.

## Structure

- `index.html`: the landing page (GAMAP v2.17 splash). It links into `doc/`.
- `gamap.css`: the shared stylesheet. Pages use its `sizeNN[b][i]` font classes (for example `size20bi`), and pages under `doc/` reference it as `../gamap.css`.
- `doc/index.html`: a `<frameset>`, with `Contents.html` (TOC, 210px wide) on the left and `Chapter_N.html` in the `gamap_view_frame` frame on the right. `Contents.html` uses `expanding_menu.js`/`.css` for its collapsible tree, and its links target section anchors such as `Chapter_3.html#3.2.1`.
- `doc/Chapter_0.html` to `Chapter_8.html`: the hand-written User Guide (v2-19). Each chapter has Previous/Next links to its neighbours, and section anchors use `<A NAME="x.y.z">`. Changes to the section structure must be mirrored in `Contents.html`.
- `doc/all_routines/`, `doc/by_alphabet/gamap_[a-z].html`, `doc/by_category/*.html`: the per-routine reference pages. IDL's `mk_html_help.pro` generated them from routine header comments (each starts with `<!-- This file was generated by mk_html_help.pro -->`). The generator and the IDL sources are not in this repo, so fix these pages by editing the HTML directly. Every one of them repeats the same navigation block (all-routines, category, and letter links), so a change to that block has to be made in every file.
- `doc/revisions/REVISIONS_*`: plain-text modification histories for each GAMAP source directory, last updated in 2016.
- `doc/files/`: sample GAMAP config files (`diaginfo.dat`, `tracerinfo.dat`, `gamap.defaults`, `idl_startup.pro`).
- `doc/img/`: images shared by all pages.

## Conventions and caveats

- The HTML is legacy, from the early 2000s (uppercase tags, `BGCOLOR`, framesets, table layout). Leave it as it is. Do not modernize it unless asked.
- All internal links are relative. Keep them that way, because the site is served from the `/gamap-manual/` subpath.
- Some pages still contain dead links from the original site, such as `file:///C|/...` paths and `../gamap2_manual/files/...` in `Chapter_1.html`. Fix them only when asked.
